## 定义记录格式

每个确认进入术语表的概念使用稳定 ID；定义控制在一至两句话，并把适用范围、原文定位与解释状态分开记录。

```text
概念 ID：TERM-0001（模板示例，尚未分配）
规范名称：
定义：待核实
易混淆词／不建议混用的词：
来源 ID 与章节／条款定位：
适用版本、平台、模式与限制：待核实
原文与项目解释的区别：
相关概念或规则 ID：
确认状态：待核实／已核实／存在争议／已废止
验证案例 ID：
核验人、日期及依据：
```

来源不足时保留“待核实”，不以常见用法代替原文定义。概念合并、拆分或范围调整时保留旧 ID 的去向；涉及重要取舍时另写[建模决策](decisions/README.md)。
