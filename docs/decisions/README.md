# 建模决策记录

这里记录重要建模取舍及其变更理由。当前尚无已接受的建模或技术选型决策；本文件是记录规范，不代表已经确定领域模型。

当一个决策难以回退、需要背景才能理解，并且确实比较过不同方案时，建立独立记录。日常目录调整和资料格式转换无需单独写决策记录。

## 命名与状态

文件使用 `0001-short-title.md` 格式，ID 使用 `DEC-0001`，从第一份真实记录开始分配。状态可为“提议”“已接受”“已否决”“已废止”“被替代”。

已接受决策需要改变时，保留原记录并关联替代记录，不覆盖掉历史理由。

## 记录模板

```markdown
# DEC-编号：决策标题

- 状态：提议
- 日期：YYYY-MM-DD
- 涉及概念／规则／案例 ID：
- 适用范围：

## 问题与背景

需要解决的问题、现有约束和证据来源。

## 候选方案

各方案能表达什么、不能表达什么，以及主要取舍。

## 决策与理由

选择结果及支持它的资料或实验。未决定时明确写“尚未决定”。

## 后果与限制

收益、代价、仍然无法处理的场景及可推翻当前决定的证据。

## 验证与追溯

来源 ID、原文定位、案例 ID、验证结果及未决问题。

## 变更关系

替代了哪些记录／被哪份记录替代。
```

决策理由应区分原文事实、项目解释与实现取舍；来源身份和适用版本见 [source/index.md](../../source/index.md)。
