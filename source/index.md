## SRC-002：Markdown 格式转换稿

- 上游来源：SRC-001，逐页对应，不作为独立裁定证据。
- 本地入口：[original_rules/md/index.md](original_rules/md/index.md)。
- 数量：55 个 `.md` 文件，沿用 HTML 的相对目录结构。
- 工具：[scripts/html_to_markdown.py](../scripts/html_to_markdown.py)，依赖版本见 [environment.yml](../environment.yml)。
- 转换方式：提取规则正文区域，转换标题、段落、列表、引用和表格；重写站内页面链接为 `.md`，图片引用指向 HTML 归档资源。
- 转换边界：不保留网页导航、样式、交互和脚本；没有对规则作语义解释或人工修订。
- 核验状态：文件数量已核对；尚未完成逐条正文、表格、图片及锚点语义的一致性复核，不将“已转换”视为“已证明无损”。
- 授权状态：继承上游来源的待核验状态，格式转换不产生新的再分发授权。

引用派生文本时，同时记录对应 SRC-001 的页面路径和章节／条款。发现差异时修改转换流程或单独记录解释，避免改写只读 HTML 快照。
